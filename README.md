# 📰 Prism: 통계 보도자료에서 시작해, 다양한 뉴스로 시선을 확장하다.

**🔭 하나의 자료, 여러 시선.**

Prism은 국가데이터처의 통계 보도자료를 기준으로 관련 뉴스를 수집·제공하는 뉴스 포털입니다. 국가데이터처 RSS에서 보도자료 제목을 수집하고, 네이버 뉴스 검색 API를 통해 관련 기사를 검색합니다. 이후 기사 본문과 대표 이미지 등을 추출하여 이용자가 통계와 관련된 뉴스를 탐색할 수 있도록 구성하였습니다.

이용자는 뉴스 목록에서 관심 있는 기사를 선택하고, 기사 상세 화면과 연관 기사 목록을 통해 동일한 통계 주제가 언론에서 어떻게 다뤄지는지 살펴볼 수 있습니다.

## 🔍 분석 방법

1. **RSS 수집:** 국가데이터처 보도자료 RSS에서 뉴스 검색에 사용할 제목 및 발행기관 정보 확보(RSS 제목을 읽고 중복 제목을 제거합니다. 선택된 제목 중 개최·채용·모집·워크숍·세미나·포럼이 포함된 항목은 검색 대상에서 제외합니다.)
2. **뉴스 검색:** RSS 제목과 발행기관명을 이용해 네이버 뉴스 검색 API 호출
3. **결과 정리:** 수집한 뉴스의 중복 제거, 날짜 처리 및 결과 저장
4. **본문 추출:** 기사 원문 HTML 페이지에서 본문·대표 이미지·언론사 정보 추출(성공 여부와 처리 상태를 기록합니다.)
5. **웹 데이터 생성:** 수집·추출 결과를 `web/data.js`로 변환
6. **서비스 제공:** 뉴스 목록, 검색, 기사 상세 화면 및 연관 기사 표시

기사 본문 추출은 언론사별 페이지 구조와 `robots.txt`, 서버 응답 등에 따라 성공 여부가 달라질 수 있습니다. 본문을 확보하지 못한 경우에는 네이버 뉴스 검색 API의 요약문을 활용합니다.

## 🏆 주요 구현 결과

### 통계 보도자료 기반 뉴스 수집

국가데이터처의 통계 보도자료를 뉴스 검색의 출발점으로 활용하여, 통계 주제별로 관련 기사를 수집하는 구조를 구현하였습니다.

수집한 기사에는 검색 기준이 된 보도자료 정보를 연결하여, 이용자가 해당 기사가 어떤 통계 주제와 관련되어 수집되었는지 확인할 수 있도록 구성하였습니다.

### 기사 본문 및 대표 이미지 제공

언론사 원문 페이지에서 기사 본문과 대표 이미지 정보를 추출하여 뉴스 상세 화면에 활용합니다.

본문 추출에 실패한 경우에는 검색 API에서 제공하는 요약문을 대신 표시하도록 처리하여, 원문 수집 결과에 따른 화면 공백을 줄였습니다.

### 연관 기사 탐색

기사 상세 화면에서 동일한 검색어로 수집된 다른 기사를 연관 기사로 제공합니다.

연관 기사 목록은 네이버 뉴스 API의 검색 순위를 기준으로 구성하며, 이용자가 다른 기사를 선택해 탐색을 이어갈 수 있도록 구현하였습니다.

다만 동일 검색어로 수집되었다는 사실만으로 모든 기사의 통계적 관련성이 검증된 것은 아닙니다.

## ✨ 주요 기능

- **뉴스 목록 제공:** 수집한 기사를 카드 형태로 표시하고, 기사 제목·이미지·요약문·언론사·발행일 등 제공, 한 번에 최대 24건을 표시
- **뉴스 검색:** 이용자가 입력한 검색어를 기준으로 수집된 기사 탐색
- **기사 상세 화면:** 선택한 기사의 제목, 본문 또는 요약문, 대표 이미지 등 표시
- **연관 기사 탐색:** 동일한 검색 기준으로 수집된 다른 기사를 목록으로 제공
- **뉴스 무작위 배치:** 메인 화면의 기사 표시 순서를 무작위로 구성
- **본문·이미지 대체 표시:** 원문 본문을 확보하지 못한 경우 검색 API 요약문 활용
- **반응형 화면:** PC와 모바일 환경에 대응하는 뉴스 포털 레이아웃
- **데이터 갱신:** Python 스크립트 실행을 통해 뉴스 수집 및 웹 표시 데이터 갱신

## 📁 프로젝트 폴더 구조

`Prism/`은 저장소 루트입니다. GitHub ZIP으로 내려받으면 최상위 폴더 이름이 `Prism-main/`일 수 있습니다. 아래에서 **[생성]** 표시는 설정 또는 수집·가공 과정에서 추가되는 항목입니다.

```text
Prism/
├── .env.example                    # 공유용 환경변수 예시
├── .env                            # [생성] 개인 환경설정, Git 제외
├── .gitignore                      # Git 추적 제외 규칙
├── README.md                       # 프로젝트 설명 및 실행 안내
├── requirements.txt                # Python 의존성 목록
│
├── collect_prism_news.py           # RSS 기반 뉴스 검색 및 결과 저장
├── fetch_bodies.py                 # 기사 본문·이미지·언론사 정보 추출
├── build_prism_data.py             # 웹 표시용 data.js 생성
├── news_api.py                     # API 설정·중복 제거·날짜·결과 관리
├── news_transport.py               # HTTP 요청·환경변수·인증정보 보호
│
├── data/
│   └── query_comparison_temp.html  # 검색어별 결과 비교용 임시 보고서
│   ├── latest_prism_news.txt        # [생성] 최신 수집 폴더명
│   └── news_<실행시각>/             # [생성] 수집 실행별 결과
│       ├── rss_titles.json         # RSS 제목 목록
│       ├── articles.jsonl          # 중복을 정리한 기사 목록
│       ├── pipeline_log.json       # 수집·본문 추출·웹 데이터 생성 로그
│       ├── raw/                    # 검색어별 네이버 API 원응답
│       └── bodies/                 # 기사별 HTML·본문·메타데이터·처리 상태
│
└── web/
    ├── index.html                  # 뉴스 포털 HTML 구조
    ├── app.js                      # 뉴스 목록·검색·상세·연관 기사
    ├── styles.css                  # 반응형 웹 디자인
    ├── data.js                     # [생성] 웹에서 읽는 기사 데이터
    └── assets/
        ├── cover.svg               # 기본 기사 이미지
        └── prism.svg               # Prism 로고
```

수집 결과와 `web/data.js`는 로컬에서 생성하는 산출물입니다. 기사 데이터가 준비되어 있지 않으면 웹 화면에 뉴스가 없는 상태로 표시됩니다.

다음 파일 및 폴더는 실행 환경이나 데이터 수집 과정에서 생성·관리되며, Git 추적 대상에서 제외됩니다.

| 경로 | 역할 |
| --- | --- |
| `.env` | 개인 API 인증정보 및 로컬 환경 설정 |
| `.venv/` | Python 가상환경 |
| `data/news_.../` | 뉴스 수집 결과 및 로그 |
| `data/latest_prism_news.txt` | 최신 뉴스 수집 폴더 경로 기록 |
| `web/data.js` | 웹페이지에서 사용하는 뉴스 데이터 |
| `__pycache__/` | Python 실행 과정에서 생성되는 캐시 |

| 프로젝트 수집 데이터 | 웹페이지에서 사용할 기사 데이터 생성 | 수집 시점 및 실행 옵션에 따라 결과 변경, 실행별 `pipeline_log.json`에 기록 |
| [KOSIS](https://kosis.kr/) | 웹 하단의 외부 사이트 링크 제공, 기사 HTML 안의 KOSIS 링크 탐색 | 현재 공식 통계표 조회·수치 대조 기능은 포함하지 않음 |

뉴스 검색 결과는 검색 API가 제공하는 기사 후보이며, 기사 내용의 통계적 정확성이나 RSS 보도자료와의 완전한 일치 여부를 보증하지 않습니다.

## 🚀 이용 및 실행 방법

Prism은 현재 Python 스크립트로 뉴스를 수집하고, **로컬 웹서버에서 실행**를 통해 뉴스 포털을 실행하는 구조입니다.

실행 후 브라우저에서 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**에 접속합니다. 뉴스 카드를 선택하면 기사 상세 화면으로 이동하며, 검색창·원문 링크·연관 기사 패널을 이용할 수 있습니다.

### 1. 사전 준비

- Python 3.10 이상 설치
- 네이버 뉴스 검색 API 이용을 위한 인증정보 준비
- 인터넷 연결 필요
- Git 및 VS Code 등 개발 도구 사용 권장

아래 설치 명령어는 **Python 3.12 기준**입니다.

먼저 저장소를 복제한 뒤 프로젝트 폴더로 이동합니다.

```bash
git clone https://github.com/Stat-Official/Prism.git
cd Prism
```

### 2. 운영체제별 설치 및 환경 설정

<details>
<summary><strong>macOS 설치 방법</strong></summary>

프로젝트 폴더에서 다음 명령어를 순서대로 실행합니다.

```bash
python3.12 -m venv .venv # Python 가상환경 생성
source .venv/bin/activate # 가상환경 활성화
python -m pip install -r requirements.txt # 필요한 라이브러리 설치
cp -n .env.example .env # 환경변수 예시를 `.env`로 복사, 기존 파일은 유지
```

</details>

<details>
<summary><strong>Windows (PowerShell) 설치 방법</strong></summary>

Python 3.12와 Python Launcher(`py`) 설치 후 프로젝트 폴더에서 다음 명령어를 실행합니다.

```powershell
py -3.12 -m venv .venv  # Python 가상환경 생성
.\.venv\Scripts\Activate.ps1  # 가상환경 활성화
.\.venv\Scripts\python.exe -m pip install -r requirements.txt  # 필요한 라이브러리 설치
if (-not (Test-Path .env)) { Copy-Item .env.example .env }  # `.env`가 없는 경우 환경변수 예시 복사
```

**PowerShell 실행 정책 오류가 발생하는 경우**

`Activate.ps1` 실행이 차단되면 현재 PowerShell 세션에만 실행 정책을 적용한 뒤 다시 활성화합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
```

</details>

### 3. API 및 RSS 환경변수 설정

프로젝트 폴더의 `.env.example`을 복사하여 `.env` 파일을 생성하고, 본인의 인증정보와 설정값을 입력합니다.

| 환경변수 | 설정할 값 |
| --- | --- |
| `NAVER_API_PROVIDER` | 네이버 개발자센터: `developers`, 네이버 클라우드: `ncp` |
| `NAVER_CLIENT_ID` | 본인의 네이버 API 클라이언트 ID |
| `NAVER_CLIENT_SECRET` | 본인의 네이버 API 클라이언트 시크릿 |
| `RSS_URL` | 통계 보도자료 RSS 피드 주소, `.env.example`에 국가데이터처 RSS 주소 제공 |
| `RSS_PUBLISHER` | RSS 발행기관명, 기본 예시: `국가데이터처` |
| `RSS_COUNTRY` | RSS 발행기관의 국가, 기본 예시: `KR` |
| `NEWS_HTTP_TRANSPORT` | HTTP 요청 전송 방식 관련 설정 |

`.env` 설정 예시는 다음과 같습니다.

```dotenv
NAVER_CLIENT_ID=YOUR_CLIENT_ID
NAVER_CLIENT_SECRET=YOUR_CLIENT_SECRET
NAVER_API_PROVIDER=ncp
NEWS_HTTP_TRANSPORT=windows

RSS_URL=https://mods.go.kr/board.es?mid=a10301010000&bid=a103010100&act=rss
RSS_PUBLISHER=국가데이터처
RSS_COUNTRY=KR
```

위 설정은 `.env.example`을 기준으로 작성하였습니다. `NEWS_HTTP_TRANSPORT`는 실행 환경에 맞게 확인하여 설정합니다.

**주의:** `.env`에는 실제 API 인증정보가 포함되므로 GitHub에 업로드하지 않아야 합니다. `.env.example`은 공유용 예시 파일로 유지합니다.

### 4. 뉴스 수집 및 웹페이지 실행

macOS와 Windows 모두 가상환경이 활성화된 상태에서 아래 명령어를 순서대로 실행합니다.

가상환경을 활성화한 상태에서 **뉴스 검색 → 본문 수집 → 웹서버 실행** 순서로 진행합니다.

**① 뉴스 검색 및 수집**

```bash
python collect_prism_news.py --limit 10 --per-release 30
```

국가데이터처 RSS를 기준으로 뉴스를 검색하고 결과를 저장합니다.

| 옵션 | 의미 |
| --- | --- |
| `--limit 10` | 처리할 RSS 보도자료 수를 최대 10건으로 설정 |
| `--per-release 30` | 보도자료별 뉴스 검색 결과를 최대 30건으로 설정 |

**② 기사 본문 및 이미지 수집**

```bash
python fetch_bodies.py --limit 24
```

수집한 뉴스 중 최대 24건을 대상으로 기사 원문 페이지에 접근하여 본문 및 이미지 정보를 추출합니다.

현재 본문 수집 과정에는 실행당 도메인별 최대 3건 제한이 적용되어 있으며, `robots.txt` 및 서버 응답에 따라 일부 기사 수집에 실패할 수 있습니다.

**③ 로컬 웹 서버 실행**

```bash
python -m http.server 8000 --bind 127.0.0.1 --directory web
```

브라우저에서 아래 주소로 접속합니다.

**[http://127.0.0.1:8000](http://127.0.0.1:8000)**

웹페이지에서는 수집된 뉴스 목록을 확인하고, 검색 및 기사 상세 화면과 연관 기사 탐색 기능을 이용할 수 있습니다.

### 5. 웹 데이터만 다시 생성하는 경우

이미 저장된 뉴스 수집 결과를 활용하여 웹 표시용 데이터만 다시 생성하려면 다음 명령어를 실행합니다.

```bash
python build_prism_data.py
```

실행 결과는 `web/data.js`에 반영됩니다.

### 6. 실행 결과 및 생성 파일

| 경로 | 내용 |
| --- | --- |
| `data/news_.../` | 뉴스 수집 결과 및 로그 |
| `data/latest_prism_news.txt` | 최신 수집 결과 폴더 기록 |
| `web/data.js` | 뉴스 포털에서 사용하는 웹 데이터 |

`web/data.js`는 뉴스 검색 및 본문 수집 과정에서 자동 갱신되며, Git 추적 대상에서 제외됩니다.

따라서 저장소를 처음 복제한 경우에는 뉴스 수집 과정을 먼저 실행해야 실제 기사 데이터를 표시할 수 있습니다.

## 📖 라이선스 및 이용 안내

Prism의 소스코드와 외부 뉴스 콘텐츠는 이용 조건을 구분하여 확인해야 합니다.

- **프로젝트 소스코드:** 저장소의 라이선스 파일 및 별도 이용 조건 확인
- **국가데이터처 RSS:** 원자료 제공기관의 이용 조건 확인
- **네이버 뉴스 검색 API:** 네이버 API 이용약관 및 제공 범위 준수
- **언론사 기사 본문·이미지:** 원문 제공기관의 저작권 및 이용 조건 확인

기술적으로 기사 본문이나 이미지를 추출할 수 있더라도, 해당 콘텐츠를 별도 웹사이트에 전문 게시하거나 재배포할 권한이 자동으로 부여되는 것은 아닙니다.

실제 서비스 공개 시에는 원문 콘텐츠의 이용 허용 범위를 확인하고, 필요한 경우 검색 요약문과 원문 링크를 중심으로 제공해야 합니다.

## ⚠️ 서비스의 한계 및 유의사항

- **검색 결과의 관련성:** RSS 제목을 기준으로 검색한 결과에 국가·기준연월·통계 대상이 다른 기사가 포함될 수 있습니다.
- **통계 검증 기능과의 구분:** 현재 Prism은 관련 뉴스 탐색 서비스이며, 기사 속 통계 수치를 공식 통계와 대조하여 사실 여부를 판정하는 기능은 구현 범위에 포함되어 있지 않습니다.
- **본문 추출 제한:** 언론사별 HTML 구조, 접근 정책, `robots.txt`, 서버 응답 등에 따라 본문 추출이 실패할 수 있습니다.
- **요약문 대체:** 본문 추출에 실패한 경우 검색 API의 요약문을 사용하므로 기사 전체 내용을 확인하기 어려울 수 있습니다.
- **대표 이미지 제한:** 원문 페이지에 이미지 정보가 없거나 추출할 수 없는 경우 기본 이미지가 표시될 수 있습니다.
- **연관 기사 해석:** 연관 기사는 동일 검색어로 수집된 기사 및 네이버 API 검색 순위를 기준으로 제공하며, 통계적 관련성을 별도로 검증한 결과는 아닙니다.
- **데이터 갱신:** 뉴스 수집은 Python 스크립트 실행을 통해 수행되므로, 웹페이지에 표시되는 기사가 항상 실시간 최신 기사인 것은 아닙니다.
- **외부 서비스 의존성:** 네이버 뉴스 API 및 언론사 웹페이지의 응답과 이용 정책 변경에 따라 수집 결과가 달라질 수 있습니다.
- **저작권 및 이용 조건:** 기사 본문과 대표 이미지의 공개·재배포에는 별도 권리 검토가 필요합니다.
- **인증정보 보호:** 실제 API 키가 포함된 `.env` 파일은 GitHub에 업로드하지 않아야 합니다.
